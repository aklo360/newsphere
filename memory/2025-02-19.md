## CRITICAL: Mascot Creature Identity Fix (Late Session)

### Problem
- LLPhant customer requested "cute robotic elephant" mascot
- Output was a "circle blob" with "claw hands" - not recognizable as elephant
- QC only checked anatomy counts, not creature identity

### Root Cause
1. Only 3 creature presets existed (crab, octopus, robot)
2. Unknown creatures fell back to generic "mascot" with claws
3. No QC verification that output LOOKS like requested creature

### Fixes Implemented
1. **Added 10+ creature presets**
   - elephant (4 legs, 0 arms, TRUNK + big ears)
   - cat, dog, fox (4 paws, NO arms)
   - owl (2 wings, 2 talons, beak)
   - bunny, penguin, bear
   - All with creature-specific anatomy

2. **Creature Identity Block in Prompts**
   - New function: `buildCreatureIdentityBlock()`
   - Emphasizes creature's defining features
   - "MUST HAVE trunk" for elephant, etc.

3. **Creature QC Checks**
   - New function: `buildCreatureQCChecks()`
   - QC now checks creature identity FIRST
   - Rejects if `looks_like_creature: false`
   - Reports missing identifying features

4. **Default Anatomy Changed**
   - Old: 2 arms, 2 legs (humanoid)
   - New: 0 arms, 4 legs (quadruped - most animals)
   - Only crabs should have claws

## Logo Creative Director Mode (SHIPPED 2025-02-19)

### Architecture Upgrade
Logo service now uses the same Creative Director pattern as mascot:
- **ONE** `createLogoBrief()` call makes ALL creative decisions
- AI generates icon prompt dynamically per job
- QC criteria defined per job
- Logo registry for uniqueness tracking

### New Files
- `src/services/logo-creative-director.ts` — Main service
- `src/cli/logo-v2.ts` — CLI wrapper (`npm run logo`)
- `data/logo-registry.json` — Uniqueness tracking
- `src/learnings/logo.ts` — Added `CREATIVE_DIRECTOR_RULES`

### LogoCreativeBrief Interface
```typescript
{
  brandName: string;           // AI generates if not provided
  generatedName: boolean;
  tagline: string | null;
  
  iconConcept: string;         // "Abstract brain muscle form"
  iconDescription: string;
  iconImagePrompt: string;     // Full prompt for Gemini
  
  wordmarkApproach: "library" | "custom";
  fontFamily: string | null;
  fontWeight: number;
  
  primaryColor: string;
  secondaryColor: string;
  backgroundColor: string;
  mode: "dark" | "light";
  renderStyle: string;
  
  iconHasEyes: boolean;        // Affects style choices
  recommendedRenderStyles: string[];
  
  mustHaveFeatures: string[];  // What MUST be in icon
  qcCriteria: string[];        // What to verify
  iconComplexityTarget: number;
  
  similarExisting: string[];   // Registry lookup
}
```

### CLI Usage
```bash
npm run logo -- "AI fitness coaching"                    # AI names it
npm run logo -- "concept" --name "Brand"                 # User names it
npm run logo -- "concept" --name "Brand" --tagline "X"   # With tagline
```
