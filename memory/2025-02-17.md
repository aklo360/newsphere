## CRITICAL: Icon Design Updates (Session 2)

### Complexity Reduction — "Rule of One"
- **OLD target**: 75% complexity
- **NEW target**: 40-50% complexity
- Philosophy: "SIMPLEX > COMPLEX — always"
- Every icon has ONE distinctive visual element
- If combining 3+ concepts, simplify
- "Can a child draw it from memory?" → should be YES

### Frame Fill Requirement
- **OLD**: ~80% with "breathing room"
- **NEW**: 65-75% minimum, ideally 85%
- Icon should feel SUBSTANTIAL, not floating in whitespace
- Maximum 10-15% padding on any side
