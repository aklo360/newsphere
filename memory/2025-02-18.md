## flat-solid Render Style (NEW)

Added `flat-solid` as a new render style preset for Discord/Slack/Notion-style clean branding.

### Behavior
- **Avatar:** Programmatic render (sharp) - solid bg + flat icon silhouette, NO AI
- **Banner:** Programmatic render (sharp + canvas) - solid bg + icon + wordmark + tagline, NO AI
- **Banner variants (OG, community):** Still use Gemini adaptation from master

### Implementation Details
- Location: `src/ai.ts` - `generateRenderedAvatarWithStyle()` and `generateBannerWithStyle()`
- Converts black icon to foreground color via pixel manipulation
- Uses Plus Jakarta Sans ExtraBold for wordmark, 500 for tagline
- Banner uses icon.png from logo/ dir (NOT horizontal lockup to avoid duplicate wordmark)

### Usage
```json
{
  "renderStyle": { "preset": "flat-solid" },
  "mode": "dark",
  "colors": {
    "background": "#5865F2",
    "foreground": "#FFFFFF"
  }
}
```

## Community Banner Generation (LEARNINGS)

### Key Rules
1. **ONE mascot reference only** - pass single mascot image, not multiple poses
   - Multiple references cause inconsistency across mascots
   - Gemini creates variations from the ONE reference more consistently

2. **Nano-banana prompting** - repeat critical rules 3x in prompts
   - MASCOT FIDELITY IS #1 PRIORITY (repeat 3x)
   - Line weight, proportions, style must be EXACT

3. **Text centering** - must be PERFECTLY centered both H+V
   - 80% size is better than huge text
   - Leave center clear, mascots on edges only

### Banner Variants Script
`scripts/disclaw-banner-variants.ts` generates all formats from master:
- Twitter: 3000×1000 (3:1) - MASTER
- Community: 1200×480 (2.5:1)
- OG Card: 1200×628 (1.91:1)

Uses Gemini image-to-image to ADAPT (not crop) for different aspect ratios.

### IMAGE_MODEL Enforcement
- **ALWAYS use `gemini-3-pro-image-preview`** for ALL image generation
- Defined in `src/ai.ts` as `IMAGE_MODEL` constant
- All services import from ai.ts - single source of truth
- Scripts should also import from ai.ts, not hardcode model names
